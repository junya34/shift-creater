# Shift Creator Pro 📅

モダンなデザインと強力なヒューリスティック自動生成アルゴリズムを備えた、完全なクライアントサイドSPA（Single Page Application）のシフト作成ウェブアプリです。

## ✨ 主な機能

- **💎 プレミアムUIデザイン**: Vanilla CSSで構築された、清潔感のある高品質なグラスモーフィズム（すりガラス効果）デザインと**プレミアムライトテーマ**を採用。
- **⏱️ 15分単位の直感的なスライダー**: スタッフはカレンダーをドラッグ＆ドロップするだけで直感的に勤務可能時間を提出できます。
- **📅 曜日ごとのオペ数（必要人数）設定**: 日ごとの設定ではなく、月〜日までの曜日ごとに一度設定すれば、自動的にカレンダーの該当する曜日に必要人数が反映されます。
- **🤖 高度な自動生成アルゴリズム (Heuristic Scheduling)**:
  - **要員不足警告 & レポート**: 必要オペ数に満たない時間帯は赤くハイライトされるほか、シフト表の上に**「要員不足レポート」が一覧で自動生成**されます。
  - **労働時間の平準化**: すべてのスタッフの累計労働時間を追跡し、優先的に平準化して割り当てます。また、再生成のたびに条件が同じスタッフ間で自動で変動します。
  - **正確な労務ルールの適用**: 
    - 1日の労働時間は「最低30分〜最大8時間」。
    - 「6時間以上」の勤務には、適切なタイミング（出勤2時間後〜退勤1時間前）に自動的に「45分（3コマ）」の休憩を挿入します。
- **📊 勤務時間・休憩時間の表示**: シフト表の右端に「実働時間」および「休憩時間」が自動で計算され、横スクロールしても固定表示される便利なスティッキー列を搭載。
- **🖨️ PDF出力**: A4横向きレイアウトに最適化された専用印刷用スタイルを適用し、ワンクリックで美しいシフト表をPDFとして保存可能。
- **💾 サーバーレス（完全ローカル）**: データはすべてブラウザのLocalStorageに保存され、設定不要で瞬時に動作します。

## 🛠️ 技術スタック

- HTML5
- Vanilla CSS3 (CSS Variables, Flexbox, CSS Grid)
- Vanilla JavaScript (ES5互換, 変数競合を防ぐIIFEモジュール設計)
- LocalStorage API

## 🚀 使い方

特別なサーバー構築や依存関係のインストールは**一切不要**です。

1. このフォルダ内の `index.html` をお好きなブラウザ（Google Chrome, Safari など）で直接開いてください。
2. 左側のナビゲーションメニューから各画面へアクセスできます。
   - **Staff Portal**: 
     - 「新規登録」からスタッフを追加します（テーマカラーはパレットから自動で割り当てられます）。
     - スタッフを選択し、カレンダーのタイムラインをドラッグして希望時間を「保存」します。
   - **Manager Portal**:
     - 「必要オペ数設定」タブで曜日ごとの必要人数を入力します。
     - 「シフトを自動生成」ボタンをクリックすると、瞬時にルールに従った最適なシフトが生成されます！
     - 「確定シフト表」タブでは、不足レポートの確認、シフトの再生成、クリア、および「PDF出力」が可能です。

## 📂 フォルダ構成

```text
shift-creater/
├── index.html        # アプリケーションのメインHTML
├── css/
│   └── style.css     # UI/UXデザインのコアスタイル
├── js/
│   ├── app.js        # アプリ初期化・イベントリスナー
│   ├── store.js      # LocalStorageとのデータ送受信
│   ├── ui.js         # カレンダーや表のDOMレンダリング
│   └── scheduler.js  # シフト自動生成のコアアルゴリズム
└── README.md         # 本ドキュメント
```

## 📝 備考
データを完全にリセットしたい場合は、ブラウザの開発者ツールを開き（F12キー）、`Application` -> `Local Storage` にある `shift_creator_data` を削除してからページをリロードしてください。
